# Airplane Schedule — авиарежим по расписанию

Маленькое Android-приложение: по расписанию включает авиарежим на N минут и выключает обратно. Переключатель on/off в самом приложении. Работает без root.

## Что делает

- Каждый день в заданное время (по умолчанию 00:10) включает авиарежим.
- Через заданное число минут (по умолчанию 3) выключает его обратно.
- Переживает перезагрузку телефона (переставляет будильник заново).
- Переключателем в приложении можно временно выключить функцию, ничего не удаляя.

## Шаг 1. Собери APK

### Вариант А — без установки чего-либо, через браузер (GitHub Actions)

1. Зайди на https://github.com и создай бесплатный аккаунт, если его нет.
2. Создай новый репозиторий: кнопка "New" → любое имя, например `airplane-schedule` → Create repository. Публичный или приватный — не важно.
3. На странице пустого репозитория нажми "uploading an existing file" (или "Add file" → "Upload files").
4. Перетащи в окно браузера **всё содержимое** папки `AirplaneSchedule` из архива (все файлы и подпапки: `app`, `gradle`, `.github`, `build.gradle`, `settings.gradle`, `gradle.properties`, `README.md`) — именно содержимое, а не саму папку целиком.
5. Внизу нажми "Commit changes".
6. Перейди во вкладку "Actions" вверху репозитория. Там автоматически запустится сборка (жёлтый кружок → зелёная галочка через 3-5 минут).
7. Когда сборка завершится (зелёная галочка), кликни на неё, пролистай вниз до раздела "Artifacts" и скачай `app-debug` — это zip с готовым APK внутри.

Если сборка не запустилась сама — открой вкладку "Actions", слева выбери "Build APK", справа нажми "Run workflow".

### Вариант Б — через Android Studio на компьютере

1. Установи Android Studio (https://developer.android.com/studio) на компьютер.
2. Открой папку `AirplaneSchedule` как проект (File → Open).
3. Дай Gradle синхронизироваться (первый раз может занять пару минут, нужен интернет).
4. Build → Build Bundle(s) / APK(s) → Build APK(s).
5. Готовый файл будет в `app/build/outputs/apk/debug/app-debug.apk`.

Либо просто нажми Run ▶ при подключённом по USB телефоне с включённой отладкой — Android Studio сама поставит приложение.

## Шаг 2. Установи APK на телефон

Если собирал не через Run, а получил файл apk — перенеси на телефон и установи (может потребоваться разрешить "установку из неизвестных источников" в настройках MIUI).

## Шаг 3. Выдай разрешение WRITE_SECURE_SETTINGS (главный шаг!)

Без него приложение физически не может переключать авиарежим — так устроен Android, это не прихоть приложения.

1. Включи на телефоне: Настройки → Об устройстве → 7 раз тапни "Номер сборки" → включится режим разработчика.
2. Настройки → Для разработчиков → включи "Отладка по USB".
3. Подключи телефон к компьютеру по USB, разреши отладку в диалоге на экране телефона.
4. На компьютере установи ADB, если ещё нет (входит в Android Studio Platform Tools, или отдельно: https://developer.android.com/tools/releases/platform-tools).
5. В PowerShell/консоли выполни:
```
adb devices
```
Убедись, что телефон виден в списке.
6. Выполни команду выдачи разрешения:
```
adb shell pm grant com.example.airplaneschedule android.permission.WRITE_SECURE_SETTINGS
```

Всё, после этого ADB и компьютер больше не нужны — приложение работает автономно на телефоне.

## Шаг 4. Настрой в приложении

1. Открой приложение.
2. Введи час/минуту включения и длительность в минутах.
3. Включи переключатель, нажми "Сохранить".

## Важно для MIUI (Redmi 9)

MIUI агрессивно выгружает фоновые приложения — будильник может не сработать ночью, если этого не сделать:

- Настройки → Приложения → Airplane Schedule → Автозапуск → включить.
- Настройки → Приложения → Airplane Schedule → Экономия батареи → "Без ограничений".
- Настройки → Приложения → Airplane Schedule → Другие разрешения → разрешить "Показывать всплывающие окна в фоне" (если есть такой пункт).

Без этого MIUI может просто "убить" процесс до того, как сработает будильник.

## Если разрешение не выдаётся (ошибка SecurityException)

Значит `adb shell pm grant ...` не сработал — обычно из-за того, что телефон не был разблокирован, либо USB-отладка не разрешена для этого компьютера. Повтори шаг 3.
